O que é HTML e como funciona no Front-end

HTML é a linguagem que estrutura uma página web. No front-end, ele trabalha junto com CSS (estilos) e JavaScript (interações) para construir interfaces usadas em sites e até em apps mobile via WebView.

HTML Semântico

Usa tags como <header>, <section>, <nav> e <footer> para melhorar organização e acessibilidade.

CSS Responsivo

Layouts flexíveis e Grid permitem que o site funcione bem em telas pequenas ou grandes.

JavaScript

Controla interações, animações, botões e comunicação com APIs.

O que é um Banco de Dados e por que ele é importante

Bancos de dados armazenam informações que apps e sites precisam para funcionar. Podem ser SQL (MySQL, PostgreSQL) ou NoSQL (MongoDB, Firebase).

  • Armazenam usuários, pedidos, pagamentos e localização
  • Garantem segurança das informações
  • Permitem buscas rápidas
  • São acessados por APIs/servidores

Por que é essencial?

Sem um banco de dados, apps como iFood, Uber e Nubank não poderiam salvar dados nem mostrar informações personalizadas para cada usuário.

O que são Aplicativos Mobile e como se comunicam com Servidores

Aplicativos mobile são programas instalados em celulares. Eles não armazenam tudo no dispositivo: quase sempre precisam conversar com servidores através de APIs.

API / REST

É a ponte entre o app e o servidor. Ex.: /login, /pedido, /buscar-lojas.

Conexão com o Banco

O app não acessa o banco diretamente. É sempre através de uma API.

Apps Híbridos

Podem usar HTML/CSS/JS dentro de WebViews (ex.: iFood e Nubank usam partes híbridas).

Como HTML, Banco de Dados e Mobile se Integram

Os três trabalham juntos seguindo um fluxo de comunicação entre usuário, front-end, servidor e banco de dados.

Usuário
➡️
Front-end (HTML/CSS/JS)
➡️
API / Servidor
➡️
Banco de Dados

O servidor é o responsável por enviar e receber dados do banco e repassar para o app ou site.

Exemplos de Sistemas Reais

📌 iFood — Fluxo Completo

O usuário faz um pedido no app → o front-end envia os dados para o servidor → o servidor grava no banco de dados → o restaurante recebe o pedido → o entregador recebe a rota.

Tecnologias comuns: React Native, APIs REST, PostgreSQL, Redis.

📌 Nubank — Integração Mobile + Banco de Dados

O app do Nubank exibe saldo, transações e limite consultando APIs seguras. O banco de dados guarda todas as operações e o app só exibe o que o servidor libera.

Tecnologias comuns: Kotlin/Swift, sistemas distribuídos, bancos NoSQL.

📌 Uber — Geolocalização + APIs + Banco de Dados

O app envia localização → o servidor encontra motoristas próximos → consulta o banco de dados → devolve o motorista disponível ao usuário.

Tecnologias: GPS, APIs de rota, bancos escaláveis.
